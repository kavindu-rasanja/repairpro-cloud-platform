# Licensing and Commercial Model

## Current product decision

The current direction is a lifetime purchase model for the Sri Lankan market, with a Windows desktop client and cloud-connected multi-branch capabilities.

## Decisions still required

- What exactly does “lifetime” cover: one shop, one tenant, number of branches, number of devices and feature set?
- Is cloud hosting included for a defined period or indefinitely?
- Who pays for SMS usage and third-party provider charges?
- What happens if a customer changes PC, reinstalls Windows or transfers ownership?
- How are offline customers handled if cloud service is unavailable?
- What support and update period is included?
- What is the refund and cancellation policy?
- What happens to customer data if a licence expires or the service is discontinued?

## Required documents before sale

- End User Licence Agreement (EULA).
- Privacy notice and data-processing terms.
- Support and maintenance policy.
- Lifetime licence scope and transfer policy.
- Cloud service availability and data export policy.
- Third-party service disclosure, including SMS provider costs.

Obtain legal review before accepting commercial customers. This document is planning guidance, not a binding licence agreement.
