# ADR-0001: Product Platform and Commercial Direction

- **Status:** Accepted as current product direction
- **Date:** 2026-11-25

## Context

RepairPRO is being prepared as a commercial product for repair shops in Sri Lanka.

## Decision

- Product name: RepairPRO.
- Client platform for the current commercial release: Windows desktop application.
- Commercial model: lifetime purchase (detailed terms pending).
- Target market: Sri Lanka.
- Product direction includes cloud-connected multi-branch management and offline-aware desktop workflows.
- No AI features are in the current scope.

## Consequences

Documentation, testing and release planning prioritize Windows desktop, cloud synchronization, multi-branch authorization and commercial readiness. The actual implementation must be audited before claims are made about feature completion.
